# 내 차단 목록
# - 처음엔 비어 있습니다. 광고 도메인은 '기본 제공 목록'(AdGuard DNS, List-KR)이 막습니다.
# - 거기에 없는데 막고 싶은 도메인만 여기에 적으세요. 내 목록이 기본 제공 목록보다 먼저 적용됩니다.
# - 한 줄에 도메인 하나. 적은 도메인의 하위 도메인까지 모두 막힌다.
#   (예: example.com → ads.example.com 도 차단)
# - '#' 또는 '!' 로 시작하는 줄은 주석.
# - hosts 형식("0.0.0.0 example.com")과 "||example.com^" 형식도 그대로 붙여넣어도 된다.
# - 사이트가 깨지면 그 도메인을 지우거나 허용 목록(allow)에 넣으면 된다.
